# UI/UX Review

For UI tasks, always cover:

- Information hierarchy
- Component list
- Loading, empty, error, success, disabled states
- Responsive breakpoints
- Keyboard interaction
- Screen reader labels
- Visual consistency with existing design system
- Screenshot or browser verification plan

Do not propose purely decorative complexity unless it improves usability.
