# Project Planning

Before implementing, produce a concise plan containing:

1. Goal
2. Assumptions
3. Non-goals
4. Affected areas
5. Implementation sequence
6. Acceptance criteria
7. Verification commands
8. Risks and rollback

Do not edit files until the user or orchestrator approves the plan when the task is broad, ambiguous, or high-risk.
