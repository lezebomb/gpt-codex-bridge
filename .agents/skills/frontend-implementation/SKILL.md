# Frontend Implementation

Follow the existing framework and styling conventions. Before editing:

1. Identify framework, routing, styling, and test setup.
2. Locate existing components and design tokens.
3. Confirm target files.
4. Implement the smallest vertical slice.
5. Run lint, typecheck, tests, and UI inspection when available.

Always handle loading, error, empty, disabled, and success states when applicable.
