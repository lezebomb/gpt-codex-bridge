# Playwright UI Inspection

Use browser verification when available:

- Navigate to the changed page.
- Check core user flow.
- Inspect accessibility tree or screenshots.
- Verify empty/loading/error/success states when feasible.
- Record failures as reproducible steps.

Do not rely only on static code review for visible UI changes.
