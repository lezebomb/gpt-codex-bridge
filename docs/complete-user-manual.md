# 完整用户手册

完整中文教程见 [full-usage-tutorial-zh.md](full-usage-tutorial-zh.md)。

最短流程：

1. 在仓库根目录运行 `npm.cmd install --no-audit --no-fund`。
2. 运行 `npm.cmd run dev`。
3. 打开 `http://localhost:8787/dashboard/`。
4. 在“设置”点击“测试连接”。
5. 注册演示项目。
6. 读取文件。
7. 创建网页补丁。
8. 查看差异。
9. 应用并回滚补丁。
10. 创建演练任务。
11. 查看日志。
12. 用修复中心生成修复草案。

安装成程序和更新方式见 [windows-installer.md](windows-installer.md)。
