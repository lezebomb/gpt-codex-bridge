# MCP Center

MCP Center 是 dashboard 中的“能力中心”。它不是让主控 GPT 同时直连一堆 MCP，而是由 Bridge 统一管理能力、权限和日志。

## 当前能力

- 文件系统：内置。限定在已注册项目目录内。
- Git：内置。状态和 diff 读取低风险；提交和 PR 操作受权限控制。
- Codex 执行器：内置。支持 dry-run、cli、app-server。
- 浏览器截图：可用。通过 Codex job 或 Playwright 流程执行。
- GitHub：可用。依赖本机 `gh` 登录状态。

## 计划能力

- 库文档查询
- 网页读取
- 项目记忆
- 顺序规划

计划能力会显示为“未实现”，不会偷偷下载或启用第三方 MCP。

## 风险字段

- 读文件：是否可能读取项目文件。
- 写文件：是否可能修改项目文件。
- 联网：是否可能访问网络。
- 风险：低风险 / 中风险 / 高风险。

任何写文件、联网、安装依赖、运行命令、git commit/push 都必须遵守权限模式。
