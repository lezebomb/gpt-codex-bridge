# Codex 执行模式集成

Bridge 保留三种执行模式，普通用户在 dashboard 的“高级”页面中选择，不需要通过环境变量启动。

| 界面名称 | 内部值 | 说明 |
| --- | --- | --- |
| 演练模式 | `dry-run` | 始终可用，不启动 Codex，适合先测试完整流程 |
| 命令行模式 | `cli` | 调用本机 `codex exec ...`，跟随本机 Codex 登录状态 |
| 应用服务模式 | `app-server` | 通过 `codex app-server` 同步本工具启动的任务、消息和审批请求 |

## 推荐顺序

1. 先使用“演练模式”确认 dashboard、项目、补丁、日志、修复中心都可用。
2. 确认本机 `codex --version` 正常。
3. 再切换到“命令行模式”或“应用服务模式”。

## 应用服务模式限制

应用服务模式只同步通过 Bridge 启动的任务。直接在 Codex Desktop 中单独打开的任务，当前不保证自动出现在 dashboard。

本工具不管理账号切换，也不保存 ChatGPT/Codex 账号。切换账号由本机 Codex 自己决定；Bridge 跟随本机当前 `codex` 可见的登录状态。

## 账号读取

进入“高级”页面查看当前执行模式。只有应用服务模式才支持账号和限额读取；演练模式和命令行模式会显示当前限制说明。

## PowerShell 检查

```powershell
codex --version
```

如果命令不可用，先继续使用“演练模式”。
