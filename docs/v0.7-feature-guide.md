# 功能说明

当前版本重点是把本机 Bridge 做成可用的中文控制台。

## 已有能力

- 默认中文 dashboard，并支持中文 / English 切换。
- 自动生成并读取本机访问令牌。
- 可收起和展开的侧边栏。
- 项目注册、文件树、文件读取、上下文包。
- 网页补丁创建、差异查看、应用、回滚。
- 演练模式、命令行模式、应用服务模式。
- 应用服务模式下的审批队列。
- 有边界的交叉审查。
- 日志、诊断、修复中心。
- Windows 安装、启动、更新、修复脚本。

## 推荐试用顺序

1. 先用演练模式完成完整流程。
2. 再切换到命令行模式或应用服务模式。
3. 真实项目保持人工审查权限模式。
