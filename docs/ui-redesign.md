# 控制台 UI 重构说明

这次重构把 dashboard 从“功能堆叠页”整理成一个本地控制台，目标是默认中文、信息密度合理、侧边栏不抢主内容、表单控件清晰可读。

## 信息结构

左侧导航按工作流分组：

- 总览
- 项目与文件
- 网页补丁
- 执行器
- 审查与修复
- 系统

主导航项：

- 总览
- 项目
- 文件
- 模板
- 网页补丁
- 差异查看器
- 执行任务
- 执行器连接
- 审批
- 交叉审查
- 界面截图
- 修复中心
- 代码同步
- 日志
- 角色与技能
- 权限模式
- 设置

## 默认中文和语言切换

控制台默认使用中文。顶部提供“中文 / English”切换，选择会保存到 localStorage。

实现方式：

- 文案由 `bridge/public/app.js` 中的 `I18N` 字典管理。
- HTML 中的 `data-i18n`、`data-i18n-title`、`data-i18n-placeholder` 会在切换语言时刷新。
- 中文模式下，页面标题、导航、按钮、表单标签、错误提示、状态、空状态、权限说明都会显示中文。
- 少量品牌名、命令、路径、请求编号等技术值会保留原文，方便复制和排错。

## 设置页

设置页不再要求用户手动填写 token：

- 服务地址自动从当前本机页面读取。
- 访问令牌自动生成并只读展示。
- 用户需要换令牌时点击“重新生成令牌”。
- 执行模式和权限模式都可以在界面中选择。
- “重新读取本机配置”会清理浏览器本地缓存并重新从 `/bootstrap` 获取当前配置。

## 侧边栏

侧边栏支持展开和收起：

- 展开时显示图标和名称。
- 收起时仅显示图标。
- 收起后按钮仍保留在固定位置，可以再次展开。
- 宽度从 248px 收缩到 88px，主内容区自动填满剩余空间。

## 表单和下拉框

所有 `input`、`textarea`、`select`、`button` 使用统一深色样式。

为避免 Windows / Chromium 下出现灰底白字：

- 全局设置 `color-scheme: dark`。
- select 明确设置深色背景和浅色文字。
- option 明确设置深色背景和浅色文字。
- focus ring 使用蓝色边框和阴影。
- disabled 和 readonly 状态保留可读文字，不会完全变灰看不清。

## 错误和状态

所有 API 请求统一经过 `apiRequest`：

- 自动携带 `Authorization: Bearer <token>`。
- 首次打开调用本机 `/bootstrap` 自动填充服务地址和令牌。
- 解析请求编号、接口、HTTP 状态码、错误详情。
- 认证失败显示可操作提示。
- 网络错误显示本机服务不可达提示。
- 错误面板提供“查看日志”和“创建修复方案”入口。

## 总览页

总览页显示：

- Bridge 连接状态
- 当前执行模式
- 当前权限模式
- 已注册项目数量
- 最近任务
- 最近错误
- 快捷入口：注册项目、创建补丁、创建任务、查看日志

## 权限模式 UI

权限模式页解释：

- 只读检查：只读检查，不允许应用补丁，不允许危险执行。
- 人工审查：默认推荐，关键动作人工审查。
- 自动审查：低风险任务可自动运行，高风险仍需审批。
- 完全访问：危险模式，必须输入“我已理解风险”。

当前模式会显示在顶部和总览。

## 差异查看器

差异查看器对纯文本 diff 做基础高亮：

- 新增行：绿色背景。
- 删除行：红色背景。
- hunk：蓝色背景。
- 文件头：中性高亮。

## 响应式目标

重点保证 `1366x768` 和 `1920x1080` 可用。移动端保持单列可操作，但不是主要优化目标。
