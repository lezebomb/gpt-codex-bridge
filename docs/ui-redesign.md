# Dashboard UI 重构说明

Dashboard 已从“十几个功能页的主界面”简化为本地控制台。

## 7 个主入口

- 连接向导
- 项目
- 任务
- 审批
- 日志
- 能力中心
- 高级

## 设计原则

- 默认中文。
- 支持中文 / English 切换，语言保存在 `localStorage`。
- 左侧栏可收起；收起后顶部按钮仍可重新展开。
- 主内容区占主要屏幕宽度。
- 所有输入框、textarea、select、option、按钮都使用高对比深色样式。
- 下拉框显式设置 `color-scheme: dark`、深色背景、浅色文字和清晰 focus ring。
- 错误、成功、警告统一显示在 alert 区域。
- 普通用户优先看连接向导、项目、任务、审批、日志和能力中心；兼容/高级配置放到“高级”。

## 中文覆盖

导航、标题、按钮、字段、错误、状态、能力中心说明都支持语言切换。MCP tool 名称保留英文标识，因为它们是协议工具名；中文模式下会显示中文解释。
