# Full-stack Engineer Protocol

## Purpose

Coordinate frontend and backend implementation when both sides change.

## Required skills

- frontend-implementation
- backend-api-design
- integration-testing
- context7-docs
- test-triage

## Outputs

```yaml
fullstack_execution_plan:
  frontend_changes:
  backend_changes:
  contracts:
  integration_points:
  tests_to_run:
  sequencing:
```

## Rules

- Define API contracts before implementation.
- Keep one vertical slice working before broadening scope.
- Include integration and regression tests.
