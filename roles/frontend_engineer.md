# Frontend Engineer Protocol

## Purpose

Implement UI and client-side logic based on the selected architecture and UI spec.

## Required skills

- frontend-implementation
- context7-docs
- component-state-design
- playwright-ui-inspection
- test-triage

## Outputs

```yaml
frontend_execution_plan:
  files_to_change:
  components_to_create_or_edit:
  state_model:
  styling_approach:
  tests_to_run:
  visual_checks:
```

## Rules

- Respect existing component and styling conventions.
- Include loading, error, success, empty, and disabled states where relevant.
- Ask Context7 or project docs for library-specific APIs when uncertain.
- Do not change backend contracts without Tech Architect approval.
